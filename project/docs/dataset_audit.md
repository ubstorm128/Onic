## 4. Label → TCGA Project Verification

### 4.1 Method

The `tcga_label_verification.csv` was generated by a prior script (`verify_tcga_labels.py`) that:
1. Extracted patient IDs from TCGA barcodes (first 3 hyphen-delimited parts)
2. Queried the GDC API in batches of 200 to retrieve `project.project_id`
3. Cross-tabulated numeric labels against TCGA project codes

## 6. Patient ID Structure Analysis

### 6.1 TCGA Barcode Structure

Format: `TCGA-XX-XXXX-NN` where:
- `TCGA-XX-XXXX` = patient ID (first 3 parts)
- `NN` = sample type code

### 6.2 Sample Type Distribution (All 8,314)

| Sample Type Code | Count | Meaning |
|---|---:|---|
| 01 | 7,800 | Primary solid tumor |
| 06 | 351 | Metastatic |
| 03 | 163 | Primary blood-derived cancer (LAML) |

| Scope | Multi-Sample Patients |
|---|---:|
| All 8,314 samples | 0 |

**Implication:** Each sample ID corresponds to a unique patient. Standard stratified splitting is safe — patient-level grouping is not required. However, this finding should be re-verified after filtering.
